## 🚀 Features

- **Timeline Agenda View**: Visualize your daily schedule with a sleek, horizontal timeline. Includes an intuitive month and day selector.
- **Smart Status Indicators**: Instantly recognize task states with color-coded pills (*Selesai*, *Berlangsung*, *Akan Datang*).
- **Task Calendar & List Views**: Switch between different view modes to manage deadlines and priorities effectively.
- **Real-time Sync**: Powered by Firebase Firestore for blazing-fast, real-time data synchronization.
- **Responsive Design**: Carefully crafted UI/UX that works beautifully across different screen sizes.

## 🛠️ Built With

- HTML5 / CSS3 / Vanilla JavaScript
- [Firebase](https://firebase.google.com/) (Authentication, Firestore Database, Hosting)
- Custom CSS Animations & Smooth UI Interactions

## 💻 Getting Started

### Prerequisites
- A modern web browser.
- A Firebase project (only if you want to deploy your own backend instance).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/UnnamedPeople-Chin/schedule-organizer.git
   ```
2. Open `index.html` in your browser to view the app locally.
3. *(Optional)* To configure your own Firebase, update the `firebaseConfig` object in `app.js` with your project's credentials.
